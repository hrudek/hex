### PR A: durable archive + app feedback + JSON file export

Avoid unrestricted lifetime text array. begin never waits for migration/load; in-memory new mutations win against old async loads. Per-entry revision increases on each modification; archive UUID identifies a lineage and resets on confirmed Clear. Interrupted persisted captures become interrupted unless actively owned.
- No loss allowed just because latest snapshot coalesces: only coalesce per-entry writes, not unrelated entries. Source-of-truth entries precede index writes. Rebuild handles missing, stale, or corrupted index; do not trust a stale index to hide newer entries forever.
- Safe idempotent schema-1 migration independent of capture toggle. Validate durable per-entry copies and completion marker before deleting legacy; no overwriting newer v2 copy. Unknown/corrupt data preserved or quarantined with a generic visible issue; no destructive auto-delete. Retry failures, including protection/write failures. Quarantine in same protected backup-excluded tree; confirmed delete includes quarantine. Existing expectedText/feedbackNote survive; rating stays unrated. Handle schema-1 reappearance after downgrade without replacing newer data.

This is a deliberate owner-requested archive-retention exception to old switch behavior (request explicitly says everything permanently). Do not pause for new owner approval; coordinator accepts on that basis. Make it very explicit in UI/docs/tests/comment. Read/rate/export/delete saved logs still possible when OFF. Show count and estimated archive MB; do not scan all text on main. Do not show 'last exported' as proof that another app saved a file: use 'last JSON prepared' if tracking.

### PR B: keyboard quick feedback, nonblocking
- Separate new feature branch/worktree from merged PR A. New typr.dictationFeedbackStrip on by default in own Typr settings, OFF retains existing keyboard behavior.
- Minimal explicit feedback offer before result snapshot publish: {resultID, jobID, entryID, archiveID or captureGeneration, expiresAt}. Do not infer last global entry or alter unrelated upstream protocol unnecessarily. Keyboard displays only for this instance's freshly actually inserted matching result; no prompt merely from stored previous snapshot.
- Good / Problem / dismiss in existing tray space (compact) and full keyboard strip WITHOUT removing Undo dictation or essential next dictation/style affordances permanently. Hide on first typing, next recording, dismiss, keyboard hide; retain newly posted feedback. Bad opens optional horizontal category choices; no free-text editor inside keyboard in v1 (host-document text must never be intercepted or accidentally receive feedback).
- Pending events durable App Group bridge with one atomic file per UUID event (preferred over whole-array UserDefaults; native writes in separate processes must not clobber). Bounded max100 pending and 30-day age; reaching cap must show cannot queue or explicitly disclosed expiry, never pretend saved. Envelope eventID, matching IDs/archive generation, rating/issues, createdAt plus stable event order tie-breaker. Offers revoked on Off/Clear; generation prevents pre-clear events attaching after deletion. No dictated text in feedback queue. Restrict event filenames/size/schema; protect + backup exclude.
- App drains existing keyboard poll/activation/start, matches exact entry not latest, applies only valid/newer feedback, persists entry DURABLY before acknowledging/removing event. Crash after durable write before ack is idempotent (revision/event identity or stored applied event ID); timestamps alone not sufficient for equal timestamps/multiple rapid category taps—use stable total order and document resolution with app edits. Text editor updates separate from rating categories so queued keyboard ratings never overwrite newer free notes/reference. App startup loads/migrates archive before treating unseen entry as nonexistent. Feedback for unloaded old entry may load asynchronously, unlike late capture callbacks; deleting entry prevents its return.
- Keyboard truthful 'Queued' / 'Noted on keyboard' until durable app ACK. Full Access absent no bridge UI/action; toggles and generation checked at enqueue/consume. Protect unrelated host text/cursor. Add app/bridge/model tests plus snapshot scenes both compact and full keyboard with feedback and preserved undo.
